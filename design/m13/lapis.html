Build notes

  • Extend lapis tasks/task_tile.dart with a collapsible tree below the task row; the vertical line uses Palette.lapisSoft (#E5E9FB) in light and Palette.lapisDeep (#243068) in dark, with matching horizontal branches—keeping the lapis accent palette.
  • Add the per-device subtaskTapMode enum to AppSettings (open details + subtasks, subtasks only, details only). Store in shared settings; surface a Settings row under a new "Tasks" section in settings/settings_page.dart.
  • Tree line & subtask checkboxes re-use existing CheckRing at 16 px and the SheetPiece rounded-sheet container so the tree inherits the planner-page look.
  • Skip lives next to Done in tasks/task_detail.dart as an OutlinedButton with scheme.error foreground (#C33F2A light / #FF8F7A dark); badge in Completed uses a warm rose tint (#8A5A6A text, #F3E5EC fill) to visually separate from the lapis Done badge.
  • Skipped task row: scheme.onSurfaceVariant title with TextDecoration.lineThrough; check ring shows ↷ in a muted warm tone instead of the filled lapis circle.
  • Undo snack uses the existing SnackBarTheme: inverseSurface (#171B33) bg, Palette.lapisLight (#94A7FF) action text (dark) / Palette.lapisSoft (light).
  • "Show subtasks only" mode adds a small bordered arrow button (12 md radius, line border) on the row's end so the user can still open details; a tap anywhere else toggles the tree.
  • Missed repeats: no new widget needed—the scheduler creates a new occurrence on Today while leaving the old one in Overdue, so both appear naturally in taskListRowsProvider.
  • Calendar inline tree: render in DayAgenda and in week _DayColumn using the same SubtaskTreeWidget under each CalendarChip/ListTile.
