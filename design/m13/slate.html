Build notes

  • Affected Dart files: tasks/task_tile.dart (subtask tree & tap modes), tasks/task_detail.dart (details action bar Skip button), tasks/task_list_page.dart (unfold state & missed repeats), calendar/calendar_page.dart / calendar_widgets.dart (agenda subtasks), settings/settings_page.dart (Tasks section segmented button).
  • Data & Settings model: Add enum SubtaskTapAction { detailsAndSubtasks, subtasksOnly, detailsOnly } to shared settings stored per device in app_settings.dart; default is detailsAndSubtasks.
  • Tree line tokens: Light 2px stroke in Royal Indigo 200 (#C7D2FE) connecting 19px left-offset checkmark center to child branches; Dark 2px stroke in Indigo 900 (#39446D). Child checkboxes are 17px circular rings with Radii.sm cards.
  • Skip action & button: Placed in task_detail.dart header bar between Done and Delete. Styled as amber container (#FEF3C7 light / #452B0E dark) with Icons.skip_next_rounded.
  • Skipped appearance in Completed: Muted dashed strikethrough in #94A3B8, dashed/muted border, circular skip icon in amber, and an explicit [⇥ Skipped] pill badge (#FEF3C7 / #B45309 light, #452B0E / #FBBF24 dark).
  • Skip recurrence & Undo: Skipping a recurring task increments its anchor date to generate the next period's copy while moving the current instance to Completed. Triggers Slate's floating dark snackbar (#0F172A, Radii.md) with bold Royal Indigo (#818CF8) Undo.
  • Missed repeats: Uncompleted recurring task remains in Overdue (Yesterday/prior badge); the scheduled recurrence automatically populates Today with matching title and recurrence badge.
  • “Show subtasks only” mode: Tapping the row expands the tree in place; a dedicated trailing button (details-action-btn, Icons.chevron_right_rounded) triggers full task details navigation.
