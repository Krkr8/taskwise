Tasks and reminders, synced through your own server.

Taskwise is a to-do app for Windows, Linux, Android, iPhone and the browser. Your tasks live on a server you run yourself. It is free and open source (MIT). Source on GitHub.

Your own server

Taskwise syncs through a small server that only you control. Run your own server.
